# Logoipsum — landing page con Bootstrap y Sass

Sitio de práctica para trabajar la maquetación responsive y la personalización de componentes de Bootstrap mediante Sass.

## Tecnologías

- HTML5
- CSS
- Bootstrap 5
- Sass
- Font Awesome

## Ejecutar localmente

Cloná el repositorio y abrí el archivo `index.html` en tu navegador:

```bash
git clone https://github.com/cgldev/demo-bs-sass.git
cd demo-bs-sass
```

Para recompilar estilos mientras trabajás sobre los archivos Sass, instalá Sass CLI en tu entorno y ejecutá:

```bash
npm install
npm run compile:sass
```

## Alcance

Es una demo de interfaz frontend; no incluye backend ni persistencia de datos.
